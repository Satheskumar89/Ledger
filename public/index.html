How this works

Using the ledger

Tap a category tile to start an entry — pick the amount on the keypad, add a note or tag if you want, then Add entry. Net, In, and Out update right away for the month you're viewing.

Swipe an entry left to delete it, right to edit it (or hover the row if you're on a trackpad or mouse). Switch to By category to see totals grouped instead of a flat list.

Use the arrows, or tap the month name, to move between months — tapping the current month jumps back to today.

Tap the calendar to flip it over for the month's Net, In and Out. The currency shown in the corner of that side is a button — tap it to change currency, and every figure in the app follows.

Repeats

Start an entry as usual, then tap the repeat button next to the date to turn it into a repeat — monthly, weekly, quarterly or yearly. The Repeats tab lists everything that recurs.

Nothing is ever added to the ledger on its own. When a repeat comes due it waits under Waiting for you with a count on the tab. Fixed amounts confirm in one tap on the check; ones set to Varies carry a pencil instead and open the keypad with last month's figure filled in, so you can correct it.

When an amount changes, open the repeat and use Schedule a change — you can date it in the future, so next year's increase can be entered today. Entries already in the ledger keep the amount they were confirmed at; only months from the change's date use the new one.

Editing an entry that came from a repeat asks whether you mean just that month or every month from then on. Swiping it away, or choosing Skip, drops that one month and leaves the repeat running.

Where your data lives

Everything is stored locally in this browser, on this device, by default. There's no account, and nothing leaves this device unless you turn on sync yourself.

That also means a different browser, a different device, or a cleared cache won't have it — unless you've set up Sync across your devices below, or kept an Export backup file.

Sync across your devices

Tap Enable cloud sync at the bottom of the page to get a sync code, something like otter-4821-a1b2. Enter that same code on another device to link it to the same ledger — entries, repeats, and your currency setting all travel with it.

Once two devices share a code, opening the app on either one brings the older side up to date automatically — add an expense on your phone, then open this page on your laptop, and it appears there without doing anything else. Each saved copy carries a version number, and a device only accepts a copy that is genuinely further along than its own, so a device that has been closed for a week can't push its stale ledger over what you've done since.

If both sides changed — you edited on your phone while it was offline, and on your laptop in the meantime — there is no correct automatic answer, so sync stops and says so rather than picking one and destroying the other. That's what the two buttons are for: Pull from cloud replaces this device with the cloud copy, Push to cloud replaces the cloud copy with this device. It's built for one person moving between their own devices, not several people editing at once.

There's no password. The code itself is what protects your data, the same way a shared Google Docs link works — anyone holding it can read or overwrite that ledger, so treat it like a link you wouldn't want posted publicly.

Bookmark this page, or add it to your Home Screen, once sync is on. The code is saved on this device too, but that's exactly what a storage wipe takes with it — the bookmarked link is the real safety net, since the code travels along with it.

Sync now checks and reconciles immediately if you don't want to wait for the next launch; Turn off stops syncing this device without deleting what's already stored under the code.

Clearing data

With sync on, "delete my data" has to say which copy, so there are three:

This device empties the ledger here and leaves the cloud copy alone — which means the next sync brings it straight back. That's the point of sync, so use this when you want a fresh start on one device, not to get rid of the data.

Cloud only deletes the stored copy and keeps what's on this device. It also turns sync off here, because otherwise this device would simply re-upload its copy seconds later. Any other device still holding the code can re-upload its own, so clear those too if you want it gone for good.

Both deletes the cloud copy and empties this device, and turns sync off. This is the one that cannot be undone — export a backup first if there's any doubt.

Tags

The chips under the amount are quick-fill shortcuts for the memo field — tap one to fill it in, tap it again to clear it.

Tap + to type a new one. It's saved for that category and shows up as a chip from then on. Anything you type as a memo becomes a suggestion too, and the list reorders toward whatever you actually use most.

Press and hold a chip to remove it from that category's row — the toast that follows offers an Undo. After that it stays gone even if you keep using the same memo, until you type it back in with +. Removing a chip only removes the suggestion; entries already filed under it keep their memo.

Add to your iOS Home Screen

  1. Open this page in Safari — only Safari can add web pages to the Home Screen on iOS.
  2. Tap the Share icon in the toolbar.
  3. Scroll down, tap Add to Home Screen, then Add.

It'll appear as its own icon and open full-screen, without Safari's address bar.

Import & export

Export backup downloads a dated JSON file with every entry and your currency setting. This is your only backup, so keep it somewhere durable.

Import backup replaces all current entries with the ones in the file you pick — export first if you're not sure you want to lose what's currently here.
